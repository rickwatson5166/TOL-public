TOL · transparent, neutral, local

See which companies your computer is sending data to.

TOL is a small program that watches a computer's network connections and reports them in plain language. It does not block anything, and it never reads what is inside the traffic.

  • Version 0.4.6
  • Mac: working, tested on an Intel Mac
  • Windows: built, tested by machine
  • Not yet code-signed

What it shows

For every outside connection, TOL lists who the data is going to, which program on the computer sent it, how much, and when it was last seen. The first time a program contacts a new company, TOL raises a notice.

What it does not do

A monitor is only useful if its limits are stated. These are TOL's.

It does not read content

Most traffic is encrypted. TOL sees the destination, the program and the amount. It does not see the words, files or pages inside.

It does not block or change anything

It only watches. Turning it off leaves the computer exactly as it was.

It can miss very short connections

A connection that opens and closes between two checks, a few seconds apart, can go unseen. The dashboard says so on screen.

Windows shows less

Windows does not give ordinary programs per-connection byte counts, so the Windows version lists connections and programs and shows amounts as n/a.

Naming the owner of an address means asking a public registry about that address. TOL asks permission before doing so, and the setting is off until the user turns it on.

Trying it

  
TOL runs on the person's own computer and shows its dashboard only on that computer. Nothing is uploaded. Downloads are shared privately, one person at a time, by whoever sent you this page.






  
TOL is early software. It is not yet code-signed, so a Mac or Windows computer will show a first-time warning when it is opened, and some managed computers may not allow it. A description of how TOL records, what it can prove and what it cannot is available alongside the download.
