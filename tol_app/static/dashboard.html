Browser observer (optional, Firefox)

Lets TOL record which hosts a page's requests went to and whether Firefox sent the privacy signal, only while you record. It keeps the host, the page host, the time and a yes/no. It reads no content and blocks nothing. Firefox runs it only in normal windows unless you allow it in private ones (Settings, Extensions, TOL observer). Its toolbar button shows a number when it works and a red ! when it cannot reach TOL.
